Poveži uređaje u stvarnom vremenu

Da bi svi u obitelji odmah vidjeli unose jedni drugih, aplikacija treba besplatan Firebase (Google) projekt — jednom ga postavite, poveže se u par minuta.

  1. Otvorite console.firebase.google.com i prijavite se Google računom.
  2. "Add project" → upišite naziv (npr. opg-ojdanic) → Continue → Create project.
  3. U lijevom izborniku: Build → Firestore Database → Create database → odaberite lokaciju (npr. europe-west) → Start in test mode.
  4. U lijevom izborniku kliknite ⚙ Settings (ispod "Project Overview") → odaberite Project settings → dolje pod "Your apps" kliknite ikonu </> (Web) → nazovite je "OPG" → Register app.
  5. Pojavit će se kod s const firebaseConfig = { ... } — kopirajte cijeli taj dio i zalijepite dolje.

Napomena: u test modu baza je otvorena svima tko ima ovaj config — sasvim dovoljno sigurno za obiteljsku evidenciju, ali izbjegavajte dijeliti config izvan obitelji.
